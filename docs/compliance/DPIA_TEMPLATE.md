## 2. هل تحتاج هذه العملية DPIA؟

> **PDPL Article 29** يُلزم بإجراء DPIA إذا توفّر أي مما يلي:

| المعيار | ينطبق؟ |
|---------|--------|
| معالجة بيانات حساسة (صحة، دين، بيانات بيومترية) | ☐ نعم ☐ لا |
| تحليل بيانات واسع النطاق (> 10,000 فرد) | ☐ نعم ☐ لا |
| مراقبة ممنهجة للأماكن العامة | ☐ نعم ☐ لا |
| اتخاذ قرارات آلية تؤثر على الأفراد (AI) | ☐ نعم ☐ لا |
| مشاركة بيانات مع أطراف ثالثة خارج KSA | ☐ نعم ☐ لا |
| معالجة بيانات أطفال دون 18 | ☐ نعم ☐ لا |

**نتيجة:** إذا كانت إجابة **أي** من الأعلاه "نعم" → DPIA إلزامية.

## 5. الضمانات المُطبَّقة / Implemented Safeguards

### 5.1 التقني (Technical)
- [x] **تشفير في الراحة:** AES-256 لجميع PII fields في PostgreSQL
- [x] **تشفير أثناء النقل:** TLS 1.3 لجميع الاتصالات
- [x] **field-level masking:** أرقام الهوية تُعرض `XXXX-XXXX-XXXX` في الـ UI
- [x] **Multi-tenant isolation:** كل مستأجر على قاعدة بيانات منفصلة
- [x] **Audit log:** تسجيل كل CRUD على البيانات الحساسة مع IP + userId
- [x] **MFA:** إلزامي للوصول إلى بيانات HR الحساسة
