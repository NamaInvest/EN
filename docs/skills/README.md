# دليل مهارات التحقق والمراجعة الشاملة (Synthesized Skills & Review Gates)
**المشروع:** Nama Invest ERP / Namasoft ERP
**آخر تحديث:** 2026-06-07

يربط هذا الدليل كافة المهارات (Skills) وقوائم الفحص (Checklists) وبوابات المراجعة (Review Gates) المستخلصة والمترجمة من المراجع البرمجية والأمنية العالمية المرفقة في `reference-repos/`.

---

## 📚 فهرس أدلة المهارات المستخلصة

### 1. مهارات جودة وأداء لغة JavaScript & TypeScript
* **المستند المرجعي:** [JS/TS Quality Skills](./JS_TS_QUALITY_SKILLS.md)
* **المراجع المستخدمة:** `You-Dont-Know-JS`, `33-js-concepts`, `javascript-questions`
* **التركيز:** إدارة الذاكرة، معالجة غير المتزامنة الآمنة (Async/Await)، تجنب تسريب الذاكرة (Memory Leaks)، والأنماط البرمجية المتقدمة.

### 2. ممارسات وأمن بيئة Node.js للتطبيقات الكبرى
* **المستند المرجعي:** [Node.js Best Practices](./NODE_BEST_PRACTICES_SKILLS.md)
* **المراجع المستخدمة:** `nodebestpractices`
* **التركيز:** هيكلة التطبيق، إدارة الأخطاء والاستثناءات غير المعالجة، كفاءة الـ Event Loop، والتحكم بالأجهزة والعمليات الخلفية.

### 3. معايير التحقق الأمني للتطبيقات المالية والمؤسسية (ASVS)
* **المستند المرجعي:** [OWASP ASVS Security Skills](./OWASP_ASVS_SECURITY_SKILLS.md)
* **المراجع المستخدمة:** `ASVS`, `owasp-asvs-checklist`
* **التركيز:** عزل المستأجرين (Tenant Isolation)، التحقق من الصلاحيات (RBAC)، حماية الجلسات والـ APIs، التشفير الآمن للبيانات، وسجلات تتبع الأحداث (Audit Logs / SIEM).

### 4. أفضل الممارسات المحاسبية والهيكلية للنظم المالية (ERP/Accounting)
* **المستند المرجعي:** [ERP & Accounting Best Practices](./ERP_ACCOUNTING_BEST_PRACTICES.md)
* **المراجع المستخدمة:** `erpnext`, `bigcapital`
* **التركيز:** توازن القيد المزدوج، منع التلاعب بالفترات المغلقة، معالجة حساب متوسط التكلفة للمخزون، وتصميم دفاتر الأستاذ الآمنة ضد التعديل (Immutable Ledgers).

---

## 🛡️ بوابات المراجعة الموحدة (Review Gates)
تطبق هذه البوابات كشروط أمان قبل دمج أي كود أو تحديثه في بيئة الإنتاج:

1. **بوابة فحص الأمان (Security Gate):** مطابقة الكود بالكامل لمتطلبات المستوى 2 و 3 من معيار ASVS (انظر معيار الأمن).
2. **بوابة صحة العمليات المالية (Financial Integrity Gate):** التأكد من عدم المساس بأي فترة محاسبية مغلقة، وإلزامية المعاملات الذرية (Transactions).
3. **بوابة كفاءة الواجهات والـ Event Loop (Performance Gate):** منع أي دوال متزامنة معطلة للـ Event Loop (Sync Blockers)، وتأمين مفاصل الـ Tooltips والتعافي التلقائي بدون تسبب في تكرار الاتصال أو شلل المتصفح.
