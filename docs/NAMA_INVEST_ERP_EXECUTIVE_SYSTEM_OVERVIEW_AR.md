## ما هو نظام Nama Invest ERP؟

**Nama Invest ERP** هو نظام إدارة موارد مؤسسية (ERP) سعودي متكامل، مبني على أحدث تقنيات الويب (Next.js 15) ومُصمَّم خصيصاً للبيئة السعودية مع امتثال كامل لمتطلبات **هيئة الزكاة والضريبة والجمارك (ZATCA)**.

يعمل النظام كـ **SaaS متعدد المستأجرين** مع إمكانية النشر المستقل، ويدعم **العمل بدون إنترنت** عبر تطبيق سطح المكتب.

## أهم ما يميز النظام

| الميزة | التفاصيل |
|--------|---------|
| **التوافق مع ZATCA** | فاتورة إلكترونية Phase 2، QR موقَّع رقمياً، XML UBL 2.1 |
| **متعدد الشركات** | عزل كامل للبيانات بين الشركات |
| **متعدد العملات** | إعادة تقييم تلقائية FX مع إدارة فروق الصرف |
| **العمل أوفلاين** | تطبيق سطح مكتب مع مزامنة تلقائية |
| **ذكاء اصطناعي** | توقع الطلب، NLQ بالعربية، مدرب المبيعات |
| **الامتثال السعودي** | GOSI، نظام مدد، Qiwa، نهاية الخدمة، Zakat، WHT |
| **الأمان المتقدم** | MFA، SSO، SIEM، سجل تدقيق شامل، PDPL |

## ارتباط الأقسام ببعضها

| الحدث | يؤثر على |
|-------|---------|
| إصدار فاتورة بيع | ← المخزون (خصم) + المحاسبة (قيد) + ZATCA (تسجيل) |
| استلام بضاعة GRN | ← المخزون (زيادة) + المحاسبة (GR/IR) |
| صرف راتب | ← المحاسبة (قيد) + البنك (صرف) + GOSI (خصم) |
| بيع أصل ثابت | ← الأصول (إخراج) + المحاسبة (ربح/خسارة) |
| مسير رواتب | ← HR + الخزينة + المحاسبة + GOSI |
| قفل الفترة | ← منع التعديل في كل الأقسام |

## ماذا يستفيد كل دور؟

### صاحب الشركة / المدير العام
- لوحة تحكم بمؤشرات الأداء الرئيسية في الوقت الفعلي
- تقارير مالية فورية بضغطة واحدة
- مراقبة أداء كل فرع ونشاط
- تنبيهات فورية عبر واتساب أو تيليجرام
- رؤية 360 درجة للشركة من أي مكان

### المدير المالي
- قوائم مالية دقيقة: P&L، ميزانية، تدفقات نقدية
- إدارة السيولة ومتابعة التدفق النقدي
- التحكم في قفل الفترات وحماية البيانات
- مراجعة انحرافات الميزانية التقديرية
- توحيد قوائم الشركات المرتبطة

### المحاسب
- جميع القيود تُنشأ تلقائياً من العمليات
- ميزان مراجعة مباشر في أي وقت
- إدارة Open Items للعملاء والموردين
- إعادة التقييم التلقائي للعملات الأجنبية
- إعداد الإقرارات الضريبية VAT/WHT/Zakat

### مسؤول المبيعات
- دورة مبيعات متكاملة من العرض للتحصيل
- تتبع فرص البيع (CRM + Kanban)
- عمولات ومبيعات تحليلية
- ZATCA مؤتمت بالكامل

### الكاشير
- واجهة POS سريعة وسهلة
- دعم كامل للعمل بدون إنترنت
- طباعة فورية وQR كود
- إدارة الوردية بضغطة واحدة

### مسؤول المستودع
- رؤية فورية للمخزون المتاح
- WMS لتنظيم الانتقاء والشحن
- تتبع بالدفعات والأرقام التسلسلية
- تحويلات سهلة بين المستودعات

### مسؤول الموارد البشرية
- إدارة موظفين كاملة
- مسير رواتب آلي مع جميع الاستقطاعات
- تكامل مع GOSI، مدد، Qiwa
- احتساب آلي لنهايات الخدمة وفق النظام السعودي
- إدارة الإجازات والحضور والانصراف

## نقاط القوة الرئيسية

### 1. الحوكمة المالية
- قيود محاسبية تلقائية لكل عملية
- قفل فترات بمستويات متعددة (Soft/Hard Lock)
- منع تعديل القيود المرحَّلة والمعتمدة
- سجل تدقيق كامل لكل تغيير

### 2. عزل بيانات الشركات (Tenant Isolation)
- كل شركة في قاعدة بيانات مستقلة تماماً
- صلاحيات مجزأة حتى على مستوى الحقول
- لا يمكن لأي مستخدم رؤية بيانات شركة أخرى

### 3. الأمان المتقدم
- تشفير كامل للبيانات
- تسجيل دخول متعدد العوامل (MFA)
- SSO مع موفري الهوية الخارجيين
- SIEM لمراقبة الأنشطة المشبوهة
- امتثال PDPL لحماية البيانات الشخصية

### 4. التقارير والذكاء الاصطناعي
- 50+ تقرير مالي وتشغيلي جاهز
- BI Builder لبناء تقارير مخصصة
- استعلام بالعربية الطبيعية (NLQ)
- توقع الطلب بالذكاء الاصطناعي

### 5. قابلية التوسع
- يعمل مع شركة من موظف واحد حتى مئات الموظفين
- دعم فروع ومستودعات ومشاريع غير محدودة
- وحدات تفعيل/إلغاء حسب الاحتياج
- نشر سحابي أو محلي

### 6. العمل بدون إنترنت
- تطبيق سطح مكتب مع مزامنة تلقائية
- POS يعمل كاملاً بدون إنترنت
- قاعدة بيانات محلية تُزامَن عند عودة الاتصال
