## الدليل السريع — لمندوب المبيعات

### إنشاء فاتورة بيع جديدة

1. اذهب إلى **المبيعات → الفواتير → فاتورة جديدة**
2. اختر العميل (ابحث بالاسم أو الكود)
3. تحقق من الرصيد المتاح (يظهر تلقائياً)
4. أضف البنود:
   - ابحث عن المنتج بالباركود أو الاسم
   - أدخل الكمية
   - السعر يأتي تلقائياً من قائمة الأسعار الخاصة بالعميل
   - أضف خصم إذا لزم
5. تحقق من الإجمالي
6. اختر شروط الدفع
7. اضغط **حفظ**

### عرض سعر → طلب → فاتورة

1. **عرض السعر**: `/sales/quotes/new`
2. أرسل للعميل
3. عند الموافقة: افتح العرض → **تحويل لطلب**
4. الطلب يحجز المخزون تلقائياً
5. عند التسليم: افتح الطلب → **إنشاء إشعار تسليم**
6. عند الفوترة: افتح إشعار التسليم → **إنشاء فاتورة**

### استرجاع جزئي من فاتورة

1. اذهب إلى الفاتورة الأصلية
2. اضغط **استرجاع**
3. حدد الكميات المرتجعة
4. النظام:
   - يرجع المخزون
   - يصدر credit note
   - يعدّل رصيد العميل
   - يلغي ZATCA إذا كان كامل

### التحقق من عمولاتي

اذهب إلى `/sales/commissions/me` لرؤية:
- العمولات المستحقة
- العمولات المدفوعة
- الهدف الشهري والإنجاز

## الدليل السريع — لكاشير POS

### بداية المناوبة (Shift Open)

1. سجل دخول بـ PIN
2. أدخل الرصيد الافتتاحي للصندوق
3. اضغط **افتح المناوبة**

### عملية بيع

1. امسح المنتجات بالباركود (أو اختر من الشاشة)
2. اضغط **دفع**
3. اختر طريقة الدفع:
   - **نقد**: أدخل المبلغ المستلم → النظام يحسب الباقي
   - **بطاقة (Mada/Visa/Apple Pay)**: يرسل للجهاز
   - **STC Pay**: ادخل رقم الهاتف
   - **Tabby/Tamara**: BNPL
4. اطبع الفاتورة
5. ZATCA يصدر QR تلقائياً

### معاملات خاصة

| المعاملة | كيف |
|---|---|
| تطبيق خصم | زر "خصم" → نسبة أو مبلغ |
| تطبيق كوبون | زر "كوبون" → امسح/أدخل الكود |
| رد منتج | زر "رد" → اختر الفاتورة الأصلية |
| تعليق الفاتورة | زر "تعليق" → استكمال لاحقاً |
| طباعة كوبون لاحقاً | زر "طباعة" → اختر الفاتورة |

### نهاية المناوبة (Shift Close)

1. اضغط **إغلاق المناوبة**
2. النظام يعرض:
   - مبيعات نقد
   - مبيعات بطاقة
   - الإجمالي المتوقع
3. أدخل العد الفعلي للنقد
4. النظام يحسب الفرق
5. إذا كان الفرق < 5 ريال: تأكيد عادي
6. إذا كان أكبر: تنبيه للمدير

## الدليل السريع — لأمين المخزن

### استلام بضاعة (GRN)

1. اذهب إلى **المشتريات → استلام البضائع → استلام جديد**
2. اختر أمر الشراء (PO)
3. النظام يعرض البنود المتوقعة
4. لكل بند:
   - امسح الباركود (يتأكد من تطابق المنتج)
   - أدخل الكمية المستلمة
   - افحص الجودة
   - حدد batch/serial إذا لزم
   - حدد المخزن والـ bin
5. الفروقات (نقص/زيادة) تظهر تلقائياً
6. اضغط **استلام**
7. النظام:
   - يحدث المخزون
   - يصدر قيد محاسبي (Inventory DR / GR-IR CR)
   - ينبه المشتريات بفاتورة قادمة

### تحويل بين المخازن

1. **المخزون → التحويلات → تحويل جديد**
2. اختر المخزن المصدر والمستلم
3. أضف البنود
4. النظام يحسم من المصدر فوراً
5. عند الوصول: اضغط **تأكيد الاستلام**
6. تحديث المخزون النهائي

### الجرد (Stocktake)

1. **المخزون → الجرد → جرد جديد**
2. اختر المخزن (أو جزء منه — zone/category)
3. ابدأ
4. للمسح المتنقل: استخدم تطبيق الموبايل
5. لكل بند: المتوقع | المعدود | الفرق
6. أكمل العد
7. النظام يصدر:
   - تقرير الفروقات
   - قيد التسوية (Adjustment DR/CR Inventory)
   - مراجعة وموافقة

### Picking للطلبات

1. **المخزون → المختار → موجاتي**
2. مهامي مرتبة حسب الأولوية
3. لكل مهمة:
   - امسح الـ bin
   - امسح المنتج
   - أكد الكمية
4. عند انتهاء الموجة: النظام يدلك على مرحلة packing

## الأسئلة الشائعة (FAQ)

### كيف أغير الـ password؟
`/profile/security` → Change Password

### نسيت كلمة المرور
في صفحة الدخول: "نسيت كلمة المرور؟" → يصلك ايميل للريست

### لا أرى صفحة معينة
صلاحيات: تحدث مع admin

### الفاتورة لا ترسل لـ ZATCA
- تحقق من شهادة ZATCA: `/settings/zatca`
- تحقق من اتصال الإنترنت
- راجع الـ queue: `/admin/zatca-queue`
- اتصل بالدعم إذا استمرت المشكلة

### قائمة الأسعار لا تطبق
- تأكد أن العميل مرتبط بقائمة أسعار
- تأكد أن المنتج مدرج في القائمة
- تأكد من سريان القائمة (effective dates)

### كيف أصدر تقرير مخصص؟
`/reports/builder` → اختر الكيان → الحقول → الفلاتر → احفظ

### كيف أعمل نسخة احتياطية لبياناتي؟
`/settings/backup` → Export (يصلك ZIP مع كل بياناتك ضمن PDPL)
