## خطة الإنتاج

### معدات التسجيل
- **Camera:** Sony Alpha 7C II (full-frame, low-light)
- **Audio:** Rode NT-USB Mini أو Shure SM7B
- **Lighting:** Aputure 120D + softbox
- **Background:** خلفية بسيطة (أبيض/رمادي)
- **Screen recording:** OBS Studio (1080p 60fps)
- **Editing:** DaVinci Resolve (مجاني) أو Premiere Pro

### المعدلات الإنتاجية
- 1 دقيقة فيديو = 3-4 ساعات إعداد + تسجيل + مونتاج
- شهر إنتاج = 15-20 ساعة فيديو
- استهداف: 80-100 دورة كاملة في 6 أشهر

### الموارد البشرية
- **Subject Matter Expert (SME)** — يكتب المحتوى
- **Presenter** — يسجل (يفضل المعرف نفسه)
- **Video Editor** — المونتاج والإخراج
- **Reviewer** — يضمن الجودة

### المعايير
- المدة: 5-15 دقيقة لكل درس (أطول من ذلك يضعف الانتباه)
- جودة: 1080p ك minimum، 4K للمحاضرات الرئيسية
- نص: ترجمة عربية وإنجليزية كاملة
- chapters: كل فيديو مقسم لـ chapters
- quiz: بعد كل module
- handout: PDF بالنقاط الرئيسية

## نموذج Course Outline

```markdown
# Course F-107: إقفال الشهر

## وصف
كيفية إقفال الفترة المحاسبية الشهرية في نماسوفت بشكل صحيح
وفقاً لـ SOCPA. يغطي السيناريوهات الأساسية والاستثناءات.

## ما ستتعلمه
- إعداد قائمة فحص ما قبل الإقفال
- تشغيل خطوات الإقفال الـ13 آلياً
- معالجة الأخطاء الشائعة
- التحقق من توازن ميزان المراجعة
- قفل الفترة ومنع التعديلات

## المتطلبات المسبقة
- F-101: شجرة الحسابات
- F-102: قيود اليومية
- F-103: التسوية البنكية

## المحتوى (Modules)

### Module 1: نظرة عامة على إقفال الشهر (8 min)
- لماذا نقفل؟
- متى نقفل؟
- الأدوار والمسؤوليات

### Module 2: قائمة فحص ما قبل الإقفال (12 min)
- التأكد من تسوية البنوك
- التأكد من POSTING كل القيود
- مطابقة الأرصدة الفرعية بالـ GL
- تنبيهات وإستثناءات

### Module 3: تشغيل الإقفال (15 min)
- بدء الـ workflow
- متابعة التقدم
- ماذا يحدث عند كل خطوة
- اختبار: لماذا فشل في الخطوة 5؟

### Module 4: ما بعد الإقفال (10 min)
- مراجعة القوائم المالية
- توليد الملخصات للإدارة
- تصدير للمدققين الخارجيين
- قفل الفترة نهائياً

### Module 5: التعامل مع الاستثناءات (10 min)
- فتح فترة مقفلة (نادر)
- التسويات بعد الإقفال
- التعديلات لـ priorYears

### Module 6: Quiz نهائي (10 min)
- 10 أسئلة
- 80% للنجاح
- شهادة المرور

## مصادر إضافية
- نص الدورة (PDF)
- ورقة عمل: قائمة فحص قابلة للطباعة
- خطوات الإقفال (chart)
- مقطع تجريبي على بيانات حقيقية
```

## شهادات الإكمال

```typescript
// عند إكمال 80% من track مع نجاح الـ quizzes
async function issueCertificate(userId: string, trackId: string) {
  const cert = await prisma.certificate.create({
    data: {
      userId,
      trackId,
      issuedAt: new Date(),
      validUntil: new Date(Date.now() + 2 * 365 * 24 * 60 * 60 * 1000), // 2 years
      certNumber: await nextCertNumber(),
    },
  });
  
  // Generate PDF
  const pdf = await generateCertPDF(cert);
  
  // Email
  await sendCertEmail(userId, pdf);
  
  // Add badge to profile
  await addBadge(userId, trackId);
}
```

## Gamification

- **Points:** اكتسب نقاط لكل درس مكتمل
- **Badges:** للـ tracks المكتملة
- **Leaderboard:** ضمن الشركة (إن وافق العميل)
- **Streaks:** متابعة يومية
- **Friend competition:** بين الزملاء

## مقاييس النجاح

- معدل إكمال الـ tracks: > 70%
- معدل النجاح في الـ quizzes: > 85%
- رضا المتعلمين (NPS): > 50
- تأثير على Support tickets: تخفيض > 40% بعد التدريب
- تأثير على adoption: > 80% feature usage بعد 30 يوم

- **Transcript:** كامل لكل فيديو، قابل للبحث
