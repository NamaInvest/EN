## 4. Testing & QA Coverage Gaps / فجوات التغطية والاختبارات المطلوبة

بالرغم من الجودة العالية والاستقرار المحقق ببرامج الفحص الحالية، تم رصد الفجوات والاحتياجات التالية:

### ⚠️ الفجوات التشغيلية المرصودة (ISS-10)
1. **غياب اختبارات الضغط والحمل (Stress/Load Testing)**:
   - **الفجوة**: غياب كلي لاختبارات قياس قدرة وتحمل النظام وقواعد البيانات تحت الضغط العالي وموجات الفوترة الضخمة (مثل ترحيل آلاف فواتير المبيعات ونقاط البيع المتزامنة في فترات الذروة والمواسم).
   - **مستوى الخطورة**: `P3 Low`.
   - **التوصية**: برمجة اختبارات محاكاة الضغط باستخدام أداة k6 أو سكربتات خاصة لقياس حدود أداء الخوادم وقدرة الاستجابة لقاعدة البيانات.
2. **غياب الفحص الآلي لعقود الـ APIs (API Contract Testing)**:
   - **الفجوة**: غياب اختبارات تلقائية تطابق مخرجات الـ API مع مخططات OpenAPI المحددة مسبقاً لرصد أي تغيرات غير معلنة في استجابة النهايات الطرفية.
   - **مستوى الخطورة**: `P3 Low`.
   - **التوصية**: دمج فحوصات مطابقة استجابة الـ API آلياً بداخل اختبارات التكامل للـ Vitest.
3. **نقص تغطية مسارات الفوترة الإلكترونية الذاتية**:
   - **الفجوة**: تحتاج اختبارات الـ Integration لتوسيع تغطية حالات الفشل المتنوعة لاستدعاءات Sandbox للـ ZATCA لتشمل رصد أخطاء الشهادات المنتهية أو أرقام الضرائب غير الصالحة.
   - **مستوى الخطورة**: `P3 Low`.
