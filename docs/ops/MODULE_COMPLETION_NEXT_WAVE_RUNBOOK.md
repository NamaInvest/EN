# دليل تشغيل الترقية وإكمال الفجوات (Module Completion Next Wave Runbook)
## Nama Invest SaaS ERP - Critical Gaps Mitigation Runbook

يوفر هذا الدليل الخطوات الخاصة بتشغيل نظام التنبيهات وترقية تغطية النسخ الاحتياطي بالخادم بشكل آمن وقراءة فقط:

---

## 1. تشغيل وتخطيط ترقية النسخ الاحتياطي (Backup Upgrade Planning)

* لمشاهدة خطة الأوامر الكافية لتغطية 100% من قواعد البيانات:
  ```bash
  node scripts/ops/backup-coverage-upgrade.js
  ```
* **تعديل السيرفر:** يجب على مسؤول الخادم نسخ الأوامر المقترحة ووضعها في ملف كرون (`cronjob`) اليومي بالخادم ليدور تلقائياً على القواعد النشطة بدلاً من وضع أسماء جامدة (hardcoded).

---

## 2. نظام التنبيهات الطارئة (Emergency Alerts System)

* تم بناء وحدة التنبيهات `telegram-alerter.ts` لإرسال تنبيهات لقناة المطورين والمهندسين.
* **كيفية الفحص محلياً:**
  تم دمج الوحدة بالاختبارات البرمجية لمحاكاة الإرسال الآمن مع فلترة وحجب كامل للمقاطع السرية.

---

## 3. التدابير والضمانات الأمنية (Safety Protections)
* يمنع تشغيل أي أمر `pg_dump` مع معاملات حذف أو استبدال.
* تظل البيئة مقيدة بقواعد القراءة فقط لتجنب أي أخطاء تشغيلية بالإنتاج.
