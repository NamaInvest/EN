# دليل الإعداد اليدوي لبيئة قاعدة بيانات الاختبار بواسطة المسؤول (TEST_DB_MANUAL_ADMIN_SETUP_AR)

يوضح هذا المستند كيفية تهيئة بيئة قاعدة بيانات الاختبار المحلية المعزولة محلياً وبشكل آمن تماماً داخل جلسة التشغيل الحالية فقط.

---

## 🚀 خطوات التهيئة في نافذة PowerShell الخاصة بجلسة الاختبار

لتشغيل الاختبارات بأمان، يجب ضبط المتغيرات التالية داخل نافذة الطرفية (Terminal) الخاصة بك قبل البدء:

```powershell
# 1. تفعيل وضع الاختبار
$env:TEST_MODE="true"

# 2. تحديد رابط قاعدة بيانات الاختبار (استبدل بالقيمة الفعلية محلياً فقط)
$env:TEST_DATABASE_URL="postgresql://username:password@localhost:5432/nama_test_disposable"

# 3. تشغيل سكربت التحقق للتأكد من سلامة المتغيرات
powershell -ExecutionPolicy Bypass -File scripts/testing/check-test-db-env.ps1
```

---

## ⛔ القواعد الأمنية والحوكمة الصارمة

1. **لا تضع** قيم الاتصال أو كلمة المرور الخاصة بقاعدة بيانات الاختبار داخل أي ملف `.env` للمشروع.
2. **لا تقم بعمل commit** لأي رابط يحتوي على كلمة مرور أو سر لـ Git.
3. **لا تطبع** المتغيرات في شاشات التقارير العامة؛ استخدم دائماً سكربت التحقق الآمن `check-test-db-env.ps1` الذي يفحص وجود المتغير بدون طباعة قيمته.
4. **تأكد** أن اسم قاعدة بيانات الاختبار يحتوي صراحة على كلمة `test` أو `disposable` لضمان عدم لمس قاعدة بيانات الإنتاج.
5. **بعد انتهاء** جلسة العمل أو الاختبار، أغلق نافذة الطرفية (Terminal) بالكامل أو قم بمسح المتغيرات باستخدام:
   ```powershell
   Remove-Item Env:\TEST_MODE
   Remove-Item Env:\TEST_DATABASE_URL
   ```
