# قائمة مراجعة تهيئة بيئة قاعدة بيانات الاختبار (TEST_DB_READINESS_RETRY_CHECKLIST_AR)

يجب على المسؤول المحاسبي أو البرمجي مراجعة هذه البنود بالكامل قبل إعادة تشغيل بوابة جاهزية قاعدة البيانات:

---

- [ ] `TEST_MODE=true` مضبوط في جلسة (session) الطرفية فقط.
- [ ] `TEST_DATABASE_URL` مضبوط في جلسة (session) الطرفية فقط.
- [ ] `TEST_DATABASE_URL` لم تتم طباعته نهائياً في التقارير أو logs.
- [ ] `TEST_DATABASE_URL` لم يتم حفظه أو ترحيله لـ Git.
- [ ] اسم قاعدة بيانات الاختبار يحتوي صراحةً على كلمة `test` أو `disposable` أو `sqlite`.
- [ ] قاعدة البيانات ليست قاعدة بيانات الإنتاج أو خادم حي.
- [ ] لا يوجد تشغيل لأمر `prisma migrate` بأي شكل.
- [ ] لا يوجد تشغيل لأمر `prisma db push` بأي شكل.
- [ ] لا يوجد كتابة أو تشغيل لـ SQL مباشر.
- [ ] المسار المعتمد هو تشغيل `readiness gate` فقط.
- [ ] فحص الدخان يتم بوضع `smoke readiness-only` فقط وبدون حركات كتابة مالم تكن transaction rollback مؤكدة.
- [ ] لا يتم إجراء أي عملية ترحيل مالي حي `no live financial posting`.
