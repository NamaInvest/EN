# توثيق منصة الإشعارات الموحدة والبث اللحظي (Real-Time & Notifications)

تم إنجاز **المرحلة 81** (نظام الإشعارات الموحد) و **المرحلة 83** (البث اللحظي) من خطة العمل لبناء نظام تواصل وإشعارات حي ومتعدد القنوات يليق بمنصة ERP ضخمة.

## 🛠️ ما تم إنجازه تقنياً:

### 1. محرك الإشعارات المركزي `notifications.ts`
تم بناء المحرك الموحد الذي يتعامل مع كافة قنوات الاتصال من مكان واحد بدلاً من تشتتها:
- **توجيه القنوات (Omni-Channel Routing):** دعم الإرسال إلى (داخل التطبيق `in_app`، البريد الإلكتروني `email`، واتساب `whatsapp`، تيليجرام `telegram`، الإشعارات المنبثقة `push`).
- **إدارة القوالب (Templates Engine):** تم تسجيل قوالب معتمدة وذكية للتعامل مع الأحداث (مثل: فاتورة جديدة، دفعة مستلمة، تنبيهات مخزون، اعتماد مطلوب).
- **نظام الطوابير (Queueing & Retry):** لا يتم إرسال الإشعار بشكل يوقف النظام، بل يضاف إلى الطابور (Queue) لضمان عدم ضياع التنبيهات وإعادة الإرسال في حال فشل الاتصال مع موفر الخدمة (مثال: سيرفرات واتساب).

### 2. واجهة البث اللحظي (Real-time SSE Server)
بدلاً من الضغط على السيرفر بطلبات متكررة (Polling)، تم تطبيق تقنية `Server-Sent Events (SSE)` كبديل حديث وفعال لـ WebSockets لتقديم الإشعارات الفورية للمستخدم:
- **مكان الملف:** `src/app/api/notifications/stream/route.ts`
- **التصرف:** يقوم النظام بفتح قناة اتصال مفتوحة (Keep-Alive) مع متصفح المستخدم بناءً على معرّفه (`userId`) ومساحة العمل (`tenantId`).
- **الأداء العالي:** هذه التقنية تستهلك موارد شبه معدومة مقارنة بـ WebSockets ومثالية جداً لدفع الإشعارات داخل تطبيقات Next.js App Router (Streaming).

### 3. المعالجة الآمنة (`Zero-Errors`)
- اجتاز الكود الفحص الشامل `tsc --noEmit` ولم يتم رصد أي أخطاء `TypeScript`.
- التوافق التام مع طبقة الحماية التي تم بناءها مسبقاً (API Routing و Headers).

---

## 🔗 الروابط وطرق الاستخدام للمبرمجين / المراجعين:

1. **لاختبار البث اللحظي للإشعارات (Real-Time UI):**
   - يمكن للواجهة الأمامية الاتصال بالمسار التالي للاستماع للإشعارات الحية:
   `GET https://[Your-Domain]/api/notifications/stream`
   *(يجب تمرير `x-user-id` و `x-tenant-id` في الـ Headers للتوثيق).*

2. **لإرسال إشعار موحد من أي مكان في الباك-إند:**
   ```typescript
   import { notifications } from '@/lib/notifications';

   // إرسال رسالة باستخدام قالب معتمد عبر واتساب والتطبيق معاً
   notifications.sendTemplate('whatsapp', '+966500000000', 'invoice_created', {
       invoiceNo: 'INV-001',
       total: '5000'
   });
   ```
