# توثيق محرك الطباعة والباركود (Print & Barcode Engine)

تم إنجاز **المرحلة 85** (طباعة الفواتير والباركود) من خطة العمل لضمان قدرة النظام على التعامل مع نقاط البيع (POS) والمخازن (Warehouses) بشكل مادي ملموس عبر طابعات الفواتير وملصقات المنتجات.

## 🛠️ ما تم إنجازه تقنياً:

### 1. محرك الباركود المركزي `BarcodeEngine`
تم بناء المحرك الموحد لإنشاء رموز الباركود بجميع المعايير المستخدمة تجارياً:
- **مكان الملف:** `src/lib/barcode-engine.ts`
- **التنسيقات المدعومة:** 
  - `Code-128`: القياسي والمستخدم عالمياً لتتبع الأصول والشحنات.
  - `EAN-13`: الرمز العالمي للمنتجات الاستهلاكية (13 رقم).
  - `QR Code`: للفواتير الضريبية (ZATCA)، الروابط، والدفع السريع.
- **توليد سريع:** توليد الباركود كـ `Base64 PNG` ليكون جاهزاً للطباعة مباشرة في الـ PDF أو عرضه في المتصفح، عبر مكتبة `bwip-js` الاحترافية كبديل نظيف لـ `canvas` لتفادي أخطاء الـ Build على السيرفرات.

### 2. محرك أوامر الطباعة (ZPL & ESC/POS)
لكي يتحدث النظام مباشرة مع طابعات المخازن ونقاط البيع بدون تدخل تعريفات الويندوز (Drivers)، تمت إضافة المترجمات التالية:
- **ZPL (Zebra Programming Language):** لتكوين الملصقات الحرارية (Product Labels & Asset Tags) بمقاسات محددة وإرسالها مباشرة لطابعات مثل Zebra أو Datamax.
- **ESC/POS (Epson Standard Code):** لطباعة إيصالات نقاط البيع (Receipts) وقص الورق تلقائياً (Partial Cut)، حيث يرسل النظام كود `Raw Buffer` للطابعة مباشرة.

### 3. المعالجة الآمنة (`Zero-Errors`)
- الكود اجتاز فحص `tsc --noEmit` بنجاح مطلق كالعادة.
- المكتبات مضافة ضمن `package.json` مع دعم أنواع الـ `TypeScript` بالكامل.

## 🔗 طرق الاستخدام للمبرمجين / واجهات العرض:

**1. لتوليد باركود منتج في الـ Frontend:**
```typescript
import { BarcodeEngine } from '@/lib/barcode-engine';

// داخل مسار API
const ean13ImageBase64 = await BarcodeEngine.generateEAN13('6281234567890');
// يُرسل للواجهة الأمامية ويُعرض عبر <img src={ean13ImageBase64} />
```

**2. للطباعة المباشرة على طابعة المخزن (Zebra):**
```typescript
import { BarcodeEngine } from '@/lib/barcode-engine';

const zplCommand = BarcodeEngine.generateZPLProductLabel({
  sku: 'MAC-M2-256',
  barcode: '628000000001',
  nameAr: 'ماك بوك اير',
  nameEn: 'MacBook Air M2',
  price: 4500,
});
// يُرسل النص zplCommand لطابعة الشبكة أو أداة QZ Tray
```
