# توثيق محرك المزامنة غير المتصلة (Offline Sync Engine)

تم إنجاز **المرحلة 86** من خطة العمل، والتي تمثل حجر الأساس لتشغيل نقاط البيع (POS) وتطبيقات المناديب في وضع عدم الاتصال (Offline Mode) بشكل آمن لضمان استمرارية الأعمال عند انقطاع الإنترنت.

## 🛠️ ما تم إنجازه تقنياً:

### 1. محرك المزامنة الذكي `OfflineSyncEngine`
تم تصميم المحرك في `src/lib/offline-sync-engine.ts` لإدارة طابور العمليات (Queue) المعلقة على أجهزة المستخدمين:
- **التخزين المؤقت (Queue Strategy):** التقاط كافة طلبات الإنشاء (إنشاء فاتورة، تحديث مخزون، عملية دفع) وتخزينها بأمان في الـ `localStorage/IndexedDB` في حالة عدم وجود اتصال بالإنترنت.
- **إعادة المزامنة التلقائية (Auto-Sync):** بمجرد عودة الاتصال، يمر المحرك على الطابور ويرسل العمليات للـ API بشكل تسلسلي لتجنب تكرار العمليات.
- **إدارة التضارب (Conflict Resolution):** في حال فشل مزامنة عنصر معين بعد 3 محاولات (Retries)، يتم وضع العملية في حالة `Conflict` ليقرر المشرف اليدوي ما إذا كان سيقوم بإعادة المحاولة الإجبارية (Force Retry) أو الإلغاء (Discard).

### 2. التوافق التام (PWA Readiness)
هذا المحرك يكمل بيئة تطبيقات الويب التقدمية (PWA) بحيث تتصرف نقاط البيع وكأنها تطبيقات أصلية (Native)، مما يحل إحدى أكبر مشاكل أنظمة الـ ERP السحابية في قطاعات التجزئة في السعودية.

### 3. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام، ما يجعله متيناً للاستخدام في الإنتاج الفعلي للـ POS.

## 🔗 طريقة الاستخدام في الواجهات (Frontend/React):

**1. إضافة عملية للطابور عند انقطاع الشبكة:**
```typescript
import { OfflineSyncEngine } from '@/lib/offline-sync-engine';

if (!navigator.onLine) {
   await OfflineSyncEngine.addToQueue('CREATE_INVOICE', invoiceData);
   alert('تم حفظ الفاتورة محلياً وسيتم مزامنتها عند عودة الاتصال');
}
```

**2. المزامنة التلقائية عند عودة الإنترنت:**
```typescript
window.addEventListener('online', async () => {
    // سيقوم المحرك بدفع كافة الفواتير المخزنة إلى الخادم وإعطائك تقريراً بالنجاح والفشل
    const result = await OfflineSyncEngine.sync(async (action) => {
        const response = await api.post('/invoices', action.payload);
        return response.ok;
    });
    console.log(`تمت مزامنة ${result.syncedCount} فاتورة بنجاح.`);
});
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
