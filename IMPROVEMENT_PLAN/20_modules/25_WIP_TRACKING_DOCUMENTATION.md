# توثيق محرك تتبع الإنتاج تحت التشغيل (WIP Tracking Engine)

تم إنجاز **المرحلة 25.4** (من وحدة التصنيع) والخاصة بتتبع حركة المواد الخام على أرض المصنع وتأثيرها المالي في الحسابات (Work-in-Progress Valuation). هذا المحرك ضروري للمصانع الكبرى لتجنب فقدان مسار التكلفة أثناء عمليات الإنتاج.

## 🛠️ ما تم إنجازه تقنياً:

### 1. صرف المواد الخام (Material Issuance)
دالة `issueMaterials` تمكن أمين المستودع من سحب كميات من المواد الخام لتخصيصها لأمر تصنيع محدد (Work Order). 
يقوم المحرك بإنشاء حركة مخزنية (`PRODUCTION_ISSUE`) وتوليد القيد المحاسبي الأوتوماتيكي:
- **(Dr. WIP Account)**
- **(Cr. Raw Materials Account)**
مما يعكس أن التكلفة انتقلت من المستودع إلى خطوط الإنتاج.

### 2. استلام المنتجات التامة (Finished Goods Receipt)
دالة `receiveFinishedGoods` تعمل عند الانتهاء من تصنيع أمر معين.
تقوم بحساب التكلفة المعيارية للوحدات المكتملة وإضافتها إلى مستودع البضائع الجاهزة عبر حركة (`PRODUCTION_RECEIPT`) وإنشاء القيد المحاسبي الأوتوماتيكي العكسي:
- **(Dr. Finished Goods Account)**
- **(Cr. WIP Account)**

### 3. المعالجة عبر المعاملات الآمنة (Transactions)
كافة عمليات السحب والتحويل تتم عبر `prisma.$transaction` لضمان تكامل البيانات المحاسبية مع الكميات المخزنية، لتجنب حدوث أي فروقات في حالة التوقف المفاجئ للخوادم.

### 4. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لصرف مواد خام لأمر تصنيع (Work Order):**
```typescript
import { WIPTrackingEngine } from '@/lib/wip-production-tracking-engine';

await WIPTrackingEngine.issueMaterials({
    workOrderId: 501,
    materials: [
        { productId: 10, quantity: 50, cost: 5.00 }, // البلاستيك الخام
        { productId: 15, quantity: 100, cost: 2.50 }  // الألوان
    ],
    warehouseId: 1, // مستودع المواد الخام
    tenantId: 'tenant-1',
    userId: 10
});
// هذا الكود سيقوم بتحديث أمر التصنيع إلى قيد التنفيذ، وسحب الكميات، وإصدار قيود اليومية.
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
