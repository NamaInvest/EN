# توثيق محرك التهيئة الوظيفية (Employee Onboarding Engine)

تم إنجاز **المرحلة 26.1** (من وحدة الموارد البشرية - HR) الخاصة بأتمتة مهام تعيين الموظفين الجدد (Onboarding Workflow)، لضمان انسيابية العمل بين الأقسام المختلفة وتجنب التأخير في توفير المستلزمات الإدارية والتقنية.

## 🛠️ ما تم إنجازه تقنياً:

### 1. قالب المهام الآلي (Automated Task Template)
بمجرد تحويل حالة المرشح إلى موظف جديد عبر دالة `initiateOnboarding`، يقوم المحرك برمجياً بنسخ وتوزيع قالب معياري من المهام (Checklist) يشمل:
- إنشاء الحسابات البريدية وأنظمة الدليل النشط (IT).
- تسليم العهد والأجهزة المحمولة (IT).
- استكمال مسوغات التعيين والتوقيع على اتفاقية عدم الإفشاء (Employee).
- الجولة التعريفية بالشركة (HR).
- مقابلة تقييم الأسبوع الأول (Manager).

### 2. التوزيع والتفويض (Role-Based Assignment)
يتم تحديد تاريخ الاستحقاق (`dueDate`) لكل مهمة بناءً على عدد الأيام المسموحة من تاريخ التعيين، وتوجه المهام برمجياً إلى الشاشات الخاصة بكل دور (`assignedToRole`).

### 3. التفعيل التلقائي (Auto-Activation)
عند إغلاق الموظف والأقسام المعنية لجميع المهام المسندة إليهم عبر دالة `completeTask`، يتحقق المحرك من رصيد المهام المتبقية. 
إذا وصل الرصيد إلى الصفر، يقوم النظام أتوماتيكياً بنقل حالة الموظف من `ONBOARDING` إلى `ACTIVE` ليبدأ باحتساب الرواتب وتفعيل الصلاحيات الكاملة في نظام ERP.

### 4. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لبدء دورة تعيين موظف جديد فور توقيع العقد:**
```typescript
import { EmployeeOnboardingEngine } from '@/lib/employee-onboarding-engine';

await EmployeeOnboardingEngine.initiateOnboarding(
    'tenant-1', 
    105, // Employee ID
    5    // Department ID (Sales)
);
// سيتم بناء وتوزيع المهام للأقسام المعنية تلقائياً
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
