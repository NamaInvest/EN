# توثيق محرك إدارة عقود الموردين (Vendor Contract Management Engine)

تم إنجاز **المرحلة 29.3** (من وحدة المشتريات - Purchases) للسيطرة الكاملة على اتفاقيات الأسعار المبرمة مع الموردين وضمان عدم تجاوز الأسعار المتفق عليها عند إصدار أوامر الشراء (POs).

## 🛠️ ما تم إنجازه تقنياً:

### 1. إدارة اتفاقيات الأسعار (Pricing Agreements)
دالة `createContract` تقوم بحفظ عقد الشراء وتجميد أسعار المواد (Items) المشمولة في العقد للفترة الزمنية المتفق عليها (`startDate` إلى `endDate`).

### 2. الحماية أثناء إصدار أوامر الشراء (PO Protection)
دالة `getContractedPrice` توفر آلية تحقق سريعة (Look-up) يمكن استدعاؤها في واجهة المستخدم (UI) أو في الباك اند. 
إذا تم اختيار مورد معين لإصدار فاتورة شراء منه، تقوم الدالة بالبحث عن "سعر العقد النشط" لهذا المنتج وإرجاعه، مما يمنع الموظف من إدخال سعر أعلى عن طريق الخطأ.

### 3. التنبيهات المبكرة للتجديد (Proactive Alerts)
دالة `checkExpiringContracts` صُممت لتعمل كوظيفة ليلية (Cron Job). تقوم بفحص العقود التي ستنتهي خلال 30 يوماً (أو أي مدة أخرى) وتُصدر إنذارات فورية لمدير المشتريات للبدء في التفاوض لتجديد العقد قبل انقطاع التوريد.

### 4. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لجلب السعر المعتمد لمنتج أثناء تعبئة أمر الشراء:**
```typescript
import { VendorContractEngine } from '@/lib/vendor-contract-engine';

const price = await VendorContractEngine.getContractedPrice(
    'tenant-1',
    150, // رقم المورد
    3005 // رقم المنتج
);

if (price) {
    console.log(`يجب استخدام السعر: ${price}`);
    // تعطيل تعديل السعر في واجهة المستخدم (UI)
} else {
    console.log(`لا يوجد عقد نشط، السعر حر`);
}
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
