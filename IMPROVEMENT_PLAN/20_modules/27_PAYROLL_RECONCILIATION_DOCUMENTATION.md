# توثيق محرك مراجعة ومطابقة الرواتب (Payroll Reconciliation Engine)

تم إنجاز **المرحلة 27.8** (من وحدة الرواتب - Payroll) الخاصة بمطابقة مسيرات الرواتب (Pre-run Validation). يعتبر هذا المحرك خط الدفاع الأخير للمدير المالي ومدير الموارد البشرية قبل اعتماد المسير ورفعه للبنوك.

## 🛠️ ما تم إنجازه تقنياً:

### 1. تحليل الفروقات الشهري (Variance Analysis)
تقوم دالة `reconcileRun` بمقارنة راتب الموظف في الشهر الحالي مع راتبه الصافي (Net Pay) في الشهر السابق.
يتم حساب فرق المبلغ (Amount) ونسبة التغير المئوية (Percentage) باستخدام مكتبة `decimal.js` لضمان الدقة المحاسبية.

### 2. محرك تنبيهات المخاطر (Anomaly Flags Engine)
يقوم المحرك بإصدار إنذارات نصية (Flags) لرواتب محددة تستوجب المراجعة اليدوية إذا تطابقت مع أحد الشروط التالية:
- `VARIANCE_SPIKE_>_15%`: إذا زاد راتب الموظف أكثر من 15% (قد يكون بسبب عمل إضافي مبالغ فيه أو علاوة غير مصدقة).
- `VARIANCE_DROP_>_15%`: إذا نقص الراتب أكثر من 15% (قد يكون بسبب غياب غير مبرر أو خصومات غير صحيحة).
- `FIRST_PAYROLL_RUN`: إذا كان هذا أول راتب يصدر للموظف للتأكد من حساب أيام العمل (Prorated) بشكل صحيح.
- `ZERO_DEDUCTIONS_WARNING`: إذا لم يتم خصم التأمينات الاجتماعية بالرغم من وجود راتب إجمالي مرتفع.

### 3. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لعمل مطابقة لمسير رواتب شهر يوليو مقارنة بيونيو:**
```typescript
import { PayrollReconciliationEngine } from '@/lib/payroll-reconciliation-engine';

const flagsReport = await PayrollReconciliationEngine.reconcileRun(
    'tenant-1', 
    502, // معرف مسير يوليو
    501  // معرف مسير يونيو
);

console.log(flagsReport);
/*
يقوم بإرجاع مصفوفة بالموظفين الذين لديهم مشاكل مالية فقط لمراجعتها، مثلاً:
[
  {
    employeeName: 'Ahmed Abdullah',
    previousNetPay: 15000,
    currentNetPay: 18500,
    variancePercentage: 23.33,
    flags: ['VARIANCE_SPIKE_>_15%']
  }
]
*/
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
