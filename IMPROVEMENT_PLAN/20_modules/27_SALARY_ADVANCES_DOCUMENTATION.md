# توثيق محرك السلف السريعة (Salary Advances Engine)

تم إنجاز **المرحلة 27.2** (من وحدة الرواتب - Payroll) الخاصة بمعالجة السلف المالية القصيرة الأجل التي يطلبها الموظف لظروف طارئة وتسترد دفعة واحدة.

## 🛠️ ما تم إنجازه تقنياً:

### 1. دورة حياة السلفة (Advance Lifecycle)
تبدأ السلفة بحالة `PENDING`، ثم تعتمد إدارياً `APPROVED`، وتُصرف نقدياً `DISBURSED`، لتنتهي بالاسترداد `RECOVERED`، مما يمنع صرف سلفة أخرى إذا لم تُسترد السابقة.

### 2. الصرف المالي الآلي (Disbursement)
عند الصرف `disburseAdvance`، يتم تسجيل القيد المحاسبي في حساب "سلف الموظفين قصيرة الأجل" (Dr) والخصم من البنك أو العهدة النقدية (Cr).

### 3. الاسترداد التلقائي في الرواتب (Payroll Recovery)
على عكس محرك القروض (Loans Engine) الذي يقسّط المبلغ، تقوم دالة `processRecovery` باسترداد كامل المبلغ (`amount`) في أقرب مسير رواتب يصدر للموظف. وتُستدعى هذه الدالة آلياً في نهاية الشهر.

### 4. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لصرف سلفة سريعة:**
```typescript
import { SalaryAdvancesEngine } from '@/lib/salary-advances-engine';

await SalaryAdvancesEngine.disburseAdvance(
    901, // Advance ID
    'tenant-1'
);
// سيتحول النظام لإصدار القيود المالية وستكون جاهزة للاسترداد نهاية الشهر.
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
