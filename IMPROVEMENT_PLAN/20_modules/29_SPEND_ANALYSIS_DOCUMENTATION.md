# توثيق محرك تحليل المشتريات (Spend Analysis Engine)

تم إنجاز **المرحلة 29.7** (من وحدة المشتريات - Purchases) وهي المعنية بتزويد الإدارة العليا والمشتريات برؤية واضحة حول النفقات وأماكن الهدر المحتملة.

## 🛠️ ما تم إنجازه تقنياً:

### 1. تحليل نفقات المشتريات بنظام (ABC Classification)
تم تطوير الدالة `analyzeSpendByCategory` لفرز ملايين المشتريات وترتيبها حسب فئات المنتجات. ثم تقوم بجمع الفئات وتصنيفها تلقائياً كالتالي:
- **(Class A):** تمثل 80% من إجمالي النفقات (تستوجب الرقابة الصارمة وعقود طويلة الأجل).
- **(Class B):** تمثل الـ 15% التالية.
- **(Class C):** تمثل آخر 5% (مصروفات نثرية يمكن التخفيف من رقابتها).

### 2. الكشف عن المشتريات المارقة (Maverick Spend)
"الإنفاق المارق" هو شراء البضائع خارج إطار العقود المعتمدة أو دون أوامر شراء (PO) مسبقة.
دالة `analyzeMaverickSpend` تقوم بالمرور على جميع فواتير الشراء، وتصطاد أي فاتورة لا تحتوي على مرجع أمر شراء (`purchaseOrderId: null`)، ثم تحسب قيمتها كنسبة مئوية من إجمالي الإنفاق، مما يسهل على مدقق الحسابات مراجعتها وإيقاف الهدر المالي.

### 3. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لتحليل المشتريات المارقة للربع الأول:**
```typescript
import { SpendAnalysisEngine } from '@/lib/spend-analysis-engine';

const maverickReport = await SpendAnalysisEngine.analyzeMaverickSpend(
    'tenant-1',
    new Date('2026-01-01'),
    new Date('2026-03-31')
);

console.log(maverickReport);
/*
{
  totalSpend: 1500000.00,
  maverickSpend: 250000.00,
  maverickPercentage: 16.66,
  flaggedInvoices: [991, 1005, 1204]
}
*/
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
