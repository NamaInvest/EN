# توثيق محرك إعادة تقييم الأصول الثابتة (Asset Revaluation Engine)

تم إنجاز **المرحلة 2A.9** (من وحدة الأصول الثابتة - Fixed Assets) والتي تتيح للشركات تطبيق نموذج إعادة التقييم (Revaluation Model) المعتمد في معايير المحاسبة الدولية (IFRS).

## 🛠️ ما تم إنجازه تقنياً:

### 1. معالجة القيمة العادلة (Fair Market Value)
الدالة `processRevaluation` تستقبل القيمة العادلة الجديدة للأصل (المقدرة من قبل مُقيّم معتمد) وتقارنها بالقيمة الدفترية الحالية (Net Book Value).

### 2. التوجيه المحاسبي الذكي (Smart Journal Routing)
- إذا كانت القيمة العادلة **أكبر** من القيمة الدفترية، يقوم المحرك باحتساب **(فائض إعادة تقييم - Revaluation Surplus)** ويسجله في حقوق الملكية (الدخل الشامل الآخر - OCI) وليس في الأرباح والخسائر، وفقاً لـ IFRS.
- إذا كانت القيمة العادلة **أقل** من القيمة الدفترية، يقوم باحتساب **(عجز/خسارة هبوط - Deficit)** ويتم تحميله فوراً على قائمة الأرباح والخسائر (P&L).

### 3. المعالجة الدقيقة والحماية المطلقة
- يتم استخدام `decimal.js` في خلفية المعالجة لمنع أي انحرافات عشرية (Floating-point errors) في الحسابات المالية الضخمة للأصول.
- يتم إحاطة جميع التحديثات بـ `prisma.$transaction` لضمان تزامن التحديثات الدفترية مع سجلات الـ Revaluation Log.

### 4. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لإجراء إعادة تقييم لمبنى زادت قيمته السوقية:**
```typescript
import { AssetRevaluationEngine } from '@/lib/asset-revaluation-engine';

await AssetRevaluationEngine.processRevaluation({
    assetId: 550, // رقم الأصل (مثال: مبنى الإدارة)
    newFairMarketValue: 5000000.00, // القيمة السوقية الجديدة 5 مليون ريال
    revaluationDate: new Date('2026-12-31'),
    tenantId: 'tenant-1',
    valuerName: 'مكتب التقييم المعتمد'
});

// النظام سيصدر تلقائياً قيد فائض (Surplus) ويرفع قيمة الأصل الدفترية.
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
