# توثيق محرك مقارنة الميزانية والانحرافات (Budget Variance Engine)

تم إنجاز **المرحلة 2C.2** (من وحدة التقارير المالية - Financial Reporting) لمراقبة الأداء المالي اللحظي للأقسام ومراكز التكلفة والتنبيه الآلي في حالة تجاوز الميزانيات المعتمدة.

## 🛠️ ما تم إنجازه تقنياً:

### 1. مطابقة الميزانية بالإنفاق الفعلي (Budget vs Actual)
تقوم الدالة `generateVarianceReport` بجلب الميزانية المرصودة (`Budgeted Amount`) لكل حساب في مركز التكلفة، ومقارنتها بما تم صرفه فعلياً (`Actual Amount`) من واقع القيود المحاسبية المرحلة.

### 2. احتساب وتصنيف الانحراف (Variance Calculation)
يتم حساب الانحراف كمبلغ مالي وكنسبة مئوية:
- **انحراف إيجابي (Favorable):** إذا كان المصروف الفعلي أقل من الميزانية المرصودة (توفير في النفقات).
- **انحراف سلبي (Unfavorable):** إذا تجاوز المصروف الفعلي سقف الميزانية المرصودة (هدر مالي).

### 3. التعليق التحليلي الآلي (Auto-commentary)
للتسهيل على متخذي القرار، يقوم المحرك بإصدار تعليقات نصية ذكية (تُحاكي تحليل المدققين الماليين) تشرح خطورة الانحراف.
مثلاً، تجاوز الميزانية بنسبة 20% يصدر تعليق: `Critical: Exceeded budget by 20.0%. Immediate review required.`

### 4. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لجلب تقرير الانحراف لمدير قسم التسويق (مركز تكلفة 10):**
```typescript
import { BudgetVarianceEngine } from '@/lib/budget-variance-engine';

const report = await BudgetVarianceEngine.generateVarianceReport('tenant-1', 10, 'Q3-2026');

console.table(report, ['accountName', 'budgetedAmount', 'actualAmount', 'variancePercentage', 'status']);
/*
سيعرض الحسابات المتجاوزة باللون الأحمر وتنبيهات الأداء المالي.
*/
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
