# توثيق محرك قائمة التدفقات النقدية (Cash Flow Indirect Engine)

تم إنجاز **المرحلة 2C.4** (من وحدة التقارير المالية - Financial Reporting) لإصدار "قائمة التدفقات النقدية - الطريقة غير المباشرة" (Indirect Method) والتي تعتبر التقرير المالي الأهم للمستثمرين والإدارة لتقييم السيولة.

## 🛠️ ما تم إنجازه تقنياً:

### 1. التدفقات من الأنشطة التشغيلية (Operating Activities)
تم تصميم المحرك ليبدأ بصافي الدخل (Net Income) من قائمة الأرباح والخسائر، ثم يقوم بالتعديلات التالية:
- **إضافة المصروفات غير النقدية:** (مثل الإهلاك والاستهلاك Depreciation) لأنها خفضت الأرباح ورقياً ولكنها لم تخرج من الخزينة.
- **تعديلات رأس المال العامل (Working Capital):** 
  - الزيادة في الأصول المتداولة (كالمخزون والعملاء) تُطرح لأنها تمتص السيولة (Cash Outflow).
  - الزيادة في الخصوم المتداولة (كالموردين) تُجمع لأنها توفر السيولة مؤقتاً (Cash Inflow).

### 2. التدفقات من الأنشطة الاستثمارية (Investing Activities)
يتم رصد الحركات النقدية الناتجة عن شراء أو بيع الأصول الثابتة (CAPEX). شراء الأصل يعتبر تدفقاً خارجاً (سالب)، وبيعه يعتبر تدفقاً داخلاً (موجب).

### 3. التدفقات من الأنشطة التمويلية (Financing Activities)
ترصد النقدية من الحصول على قروض جديدة (موجب)، سداد القروض (سالب)، وتوزيعات الأرباح (سالب).

### 4. المطابقة النهائية (Reconciliation)
يقوم المحرك بجمع (صافي التدفق التشغيلي + الاستثماري + التمويلي) للحصول على "صافي التغير في النقدية"، ويضيفه لرصيد أول المدة ليتطابق تماماً مع رصيد النقدية في الميزانية العمومية.

### 5. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لجلب تقرير التدفقات النقدية عن السنة المالية:**
```typescript
import { CashFlowIndirectEngine } from '@/lib/cash-flow-indirect-engine';

const report = await CashFlowIndirectEngine.generateStatement(
    'tenant-1',
    new Date('2026-01-01'),
    new Date('2026-12-31')
);

console.log(report);
/*
{
  operatingActivities: { netCashFromOperations: 1330000 },
  investingActivities: { netCashFromInvesting: -350000 },
  financingActivities: { netCashFromFinancing: -300000 },
  netIncreaseInCash: 680000,
  beginningCashBalance: 500000,
  endingCashBalance: 1180000
}
*/
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
