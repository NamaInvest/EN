# توثيق محرك ولاء العملاء (Loyalty & Rewards Engine)

تم إنجاز **المرحلة 28.4** (من وحدة المبيعات ونقاط البيع - Sales & POS) لتعزيز احتفاظ العملاء وبناء أنظمة المكافآت الذكية التي تندمج مع جميع فروع الشركة ومتجرها الإلكتروني.

## 🛠️ ما تم إنجازه تقنياً:

### 1. نظام كسب النقاط والترقيات (Earn & Tier System)
تقوم دالة `earnPoints` باحتساب النقاط المكتسبة عن كل فاتورة مبيعات، وتخزينها في سجل الحركات (`LoyaltyTransaction`). 
الخوارزمية تقوم بشكل فوري بحساب "إجمالي المشتريات السنوية" وترقية العميل تلقائياً في مستويات الولاء (Tiering):
- `STANDARD` (عادي)
- `SILVER` (الفضي - يتطلب 5,000 ريال)
- `GOLD` (الذهبي - يتطلب 15,000 ريال)
- `PLATINUM` (البلاتيني - يتطلب 50,000 ريال)

### 2. نظام استبدال النقاط (Redemption)
تمكين الاستبدال من خلال دالة `redeemPoints` والتي تقوم بخصم النقاط من رصيد العميل وتحويلها لخصم مالي يطبق على الفاتورة. 
تقوم الدالة فوراً بإنشاء القيود المحاسبية لمعالجة هذه العملية الماليّة (محاسبة الالتزامات - Loyalty Liability Account).

### 3. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لإضافة نقاط لعميل بعد الدفع في نقطة البيع (POS):**
```typescript
import { LoyaltyEngine } from '@/lib/loyalty-points-engine';

await LoyaltyEngine.earnPoints({
    customerId: 4402,
    invoiceId: 991,
    totalAmount: 1500.00,
    tenantId: 'tenant-1'
});
// العميل سيكسب 1500 نقطة، وإذا كان مجموعه السنوي يتخطى 5 آلاف سيصبح Silver.
```

**لاستبدال النقاط في المتجر الإلكتروني أو نقطة البيع:**
```typescript
const discount = await LoyaltyEngine.redeemPoints({
    customerId: 4402,
    pointsToRedeem: 5000,
    invoiceId: 992,
    tenantId: 'tenant-1'
});
console.log(`تم منح خصم بقيمة: ${discount} SAR`); // سيطبع 50 ريال إذا كانت النقطة بهللة.
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
