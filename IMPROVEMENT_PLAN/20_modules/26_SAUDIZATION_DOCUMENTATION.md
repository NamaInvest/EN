# توثيق محرك التوطين ونطاقات (Saudization & Nitaqat Engine)

تم إنجاز **المرحلة 26.10** (من وحدة الموارد البشرية - HR) والمخصصة لتلبية الامتثال القانوني لوزارة الموارد البشرية في المملكة العربية السعودية.

## 🛠️ ما تم إنجازه تقنياً:

### 1. حساب نسبة التوطين (Saudization Percentage)
يقوم `SaudizationNitaqatEngine` (في `src/lib/saudization-nitaqat-engine.ts`) بقراءة بيانات جميع الموظفين النشطين في المنشأة واستخراج الموظفين الحاملين للجنسية السعودية، ليقوم بحساب نسبة التوطين بدقة تامة.

### 2. تحديد نطاق المنشأة (Nitaqat Band)
يتم تصنيف المنشأة فورياً إلى أحد النطاقات (البلاتيني، الأخضر المرتفع، الأخضر المتوسط، الأخضر المنخفض، أو الأحمر) بناءً على النسبة المحسوبة.

### 3. التوجيه بالتوظيف المستقبلي (Hiring Suggestions)
يقوم المحرك بعمليات حسابية عكسية باستخدام معادلات جبرية لتحديد **عدد الموظفين السعوديين المطلوب توظيفهم بالضبط** للارتقاء للمستوى أو النطاق التالي، لتوفير رؤية واضحة لمدراء الموارد البشرية.

### 4. التنبيهات الحرجة (Critical Warnings)
إذا وقعت المنشأة في النطاق "الأحمر" أو "الأخضر المنخفض"، يقوم المحرك بإصدار رسالة تحذيرية يمكن عرضها في الـ Dashboard لتفادي إيقاف الخدمات المتعلقة برخص العمل والإقامات للموظفين غير السعوديين.

### 5. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لعرض حالة التوطين في الشاشة الرئيسية (Dashboard):**
```typescript
import { SaudizationNitaqatEngine } from '@/lib/saudization-nitaqat-engine';

const nitaqatReport = await SaudizationNitaqatEngine.calculateSaudization('tenant-1');
console.log(nitaqatReport);
/*
النتيجة:
{
  totalEmployees: 100,
  saudiCount: 25,
  nonSaudiCount: 75,
  saudizationPercentage: 25.0,
  currentBand: 'MID_GREEN',
  requiredSaudisForNextBand: 8
}
*/
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
