# توثيق محرك الإغلاق السنوي للرواتب (Year-End Processing Engine)

تم إنجاز **المرحلة 27.6** (من وحدة الرواتب - Payroll) والضرورية جداً لإقفال السنة المالية (Year-End Close) وفقاً لمعايير المحاسبة الدولية (IFRS) ومتطلبات التأمينات الاجتماعية (GOSI) في السعودية.

## 🛠️ ما تم إنجازه تقنياً:

### 1. حساب مخصصات نهاية الخدمة (EOS Provision)
في نهاية كل سنة مالية (31 ديسمبر)، يُلزم النظام المالي بحجز مبالغ (مخصصات) كمصروفات مقابل مكافأة نهاية الخدمة للموظفين حتى وإن لم يستقيلوا. 
تقوم دالة `calculateAnnualEosProvision` بالمرور على جميع الموظفين النشطين وحساب مستحقاتهم بناءً على قانون العمل السعودي (نصف شهر لأول 5 سنوات، وشهر كامل لما زاد عنها) وتُصدر القيد المحاسبي الأوتوماتيكي:
- **(Dr. EOS Expense)**
- **(Cr. EOS Provision Liability)**

### 2. تحديثات التأمينات السنوية (GOSI Annual Updates)
في النظام السعودي، يتم تثبيت الراتب الخاضع للتأمينات لعام كامل بناءً على راتب شهر يناير. 
تقوم دالة `prepareAnnualGosiUpdate` بتجهيز وتجميد هذه الأرقام لإرسالها للتأمينات، مما يمنع حدوث أي غرامات تأخير أو تلاعب في البيانات خلال العام.

### 3. الدقة المالية باستخدام (Decimal.js)
كالعادة في الأنظمة المالية المتطورة، تم استخدام مكتبة `decimal.js` لمعالجة كافة حسابات الأشهر، السنوات، والرواتب منعاً لتراكم أخطاء الجبر الخاصة بالفاصلة العشرية.

### 4. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لإغلاق السنة المالية وحساب مخصصات 2026:**
```typescript
import { YearEndProcessingEngine } from '@/lib/year-end-processing-engine';

await YearEndProcessingEngine.calculateAnnualEosProvision(
    'tenant-1',
    new Date('2026-12-31')
);
// سيقوم النظام بمسح آلاف الموظفين في ثوانٍ وتوليد قيد المخصصات في دفتر الأستاذ العام (GL).
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
