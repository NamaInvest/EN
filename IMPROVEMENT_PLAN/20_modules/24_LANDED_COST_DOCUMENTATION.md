# توثيق محرك التكلفة الإضافية للمخزون (Landed Cost Engine)

تم إنجاز **المرحلة 24.6** (من وحدة المخزون والمشتريات) والمتعلقة بتوزيع التكاليف الإضافية (مثل الشحن، الجمارك، التأمين) على تكلفة المنتجات المشتراة لضمان احتساب دقيق لتكلفة البضاعة المباعة (COGS) وقيمة المخزون وفق المعايير المحاسبية الدولية.

## 🛠️ ما تم إنجازه تقنياً:

### 1. محرك التوزيع الديناميكي (`LandedCostEngine`)
تم برمجة `src/lib/landed-cost-engine.ts` ليقوم بتوزيع التكاليف الإضافية بناءً على 3 طرق أساسية معتمدة:
- **(القيمة - Value):** يتم التوزيع بناءً على نسبة قيمة كل صنف من إجمالي الفاتورة.
- **(الكمية - Quantity):** يتم التوزيع بناءً على عدد الوحدات (مناسب للأصناف المتشابهة في الوزن والقيمة).
- **(الوزن - Weight):** يتم التوزيع بناءً على الوزن الفعلي (مناسب للشحن البحري والجوي)، مع ارتداد تلقائي (Fallback) إلى القيمة في حال عدم توفر بيانات الوزن.

### 2. دقة العمليات الحسابية (Precision Handling)
تم استخدام مكتبة `decimal.js` في المحرك لمنع أي أخطاء متعلقة بالفاصلة العشرية (`Floating Point Errors`) التي تحدث عادة في جافاسكريبت، مما يضمن أن إجمالي المصروفات سيتم توزيعه بالهللة (بدون أي فروقات) عن طريق تخصيص الفروقات الناتجة عن التقريب لآخر صنف آلياً.

### 3. الربط المحاسبي (Journal Entries Generator)
تم توفير الدالة `buildJournalEntries()` لإنشاء مسودة القيد المحاسبي المزدوج الذي يؤدي لرسملة هذه التكاليف في المخزون (Dr. Inventory, Cr. AP/Accrual).

### 4. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

## 🔗 طريقة الاستخدام للمبرمجين:

**1. لتوزيع فاتورة جمارك وشحن على فاتورة مشتريات واردة:**
```typescript
import { LandedCostEngine } from '@/lib/landed-cost-engine';

const items = [
    { id: '1', productId: 'P1', quantity: 100, unitPrice: 50 },
    { id: '2', productId: 'P2', quantity: 50, unitPrice: 200 }
];

const costs = [
    { id: 'C1', description: 'Freight', amount: 1500, allocationMethod: 'QUANTITY' },
    { id: 'C2', description: 'Customs Duty 5%', amount: 750, allocationMethod: 'VALUE' }
];

// المحرك سيرجع لكل صنف: تكلفته الأصلية، المصاريف الموزعة عليه، وتكلفة الوحدة الجديدة
const allocations = LandedCostEngine.calculateLandedCost(items, costs);
console.log(allocations);
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
