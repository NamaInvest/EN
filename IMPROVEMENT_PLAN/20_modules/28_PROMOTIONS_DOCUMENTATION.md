# توثيق محرك العروض الترويجية المتقدمة (Advanced Promotions Engine)

تم إنجاز **المرحلة 28.5** (من وحدة المبيعات ونقاط البيع - Sales & POS) لتعزيز قدرة المبيعات وتجارة التجزئة على تصميم وإطلاق حملات تسويقية وتخفيضات ديناميكية بمرونة كاملة.

## 🛠️ ما تم إنجازه تقنياً:

### 1. أنواع العروض المدعومة (Promotion Types)
المحرك الجديد (`PromotionsEngine`) يدعم حالياً معالجة القواعد التالية بلمح البصر على مستوى سلة المشتريات (Cart-Level):
- **BOGO (اشتر X واحصل على Y مجاناً):** كود ذكي يقوم بالبحث في السلة عن توفر المنتج الشرطي (Trigger) بالكمية المطلوبة، وإذا توفر، يقوم بخصم سعر منتج الهدية إذا كان في السلة، أو إضافته تلقائياً كمنتج مجاني (`unitPrice = 0`).
- **CART_THRESHOLD (خصم إجمالي):** يمنح خصمًا بنسبة (Y%) على إجمالي الفاتورة إذا تخطت قيمة المشتريات حاجزاً معيناً (X).
- **HAPPY_HOUR (الساعة السعيدة):** يقوم المحرك بمطابقة وقت نقطة البيع المحلي `currentTime` مع ساعات العرض المحددة مسبقاً، ويطبق الخصم تلقائياً إذا كانت الفاتورة تصدر في ذلك النطاق الزمني.

### 2. معالجة حسابية نقية (Decimal Accuracy)
لضمان عدم خسارة الشركات أو تضارب حسابات الضرائب بسبب الكسور العشرية في الخصومات، تم الاعتماد على مكتبة `decimal.js` في تطبيق النسب المئوية وخصميات الهللات بصرامة مالية تامة.

### 3. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لتطبيق العروض النشطة على سلة مشتريات (Cart):**
```typescript
import { PromotionsEngine } from '@/lib/promotions-engine';

const cart = [
    { productId: 101, quantity: 2, unitPrice: 25.00 }, // Espresso
    { productId: 102, quantity: 1, unitPrice: 15.00 }  // Croissant
];

// تطبيق الخصومات (هنا توجد قاعدة BOGO نشطة: اشتر 2 اسبريسو، احصل على كرواسون مجاناً)
const { updatedCart, totalDiscount } = await PromotionsEngine.applyPromotions('tenant-1', cart);

console.log(`قيمة الخصم: ${totalDiscount}`); // ستطبع: 15.00 (سعر الكرواسون تم خصمه)
console.log(updatedCart); 
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
