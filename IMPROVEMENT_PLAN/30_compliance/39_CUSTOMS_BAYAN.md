# 39 — Customs / Bayan | الجمارك

## 🟡 الأولوية: متوسط (للشركات المستوردة)

## 🔍 الفجوات (لا تكامل حالياً)
- لا customs declarations
- لا duty calculation
- لا shipment tracking
- لا certificate of origin
- لا HS code management

## 🎯 الخطة

### 39.1 — HS Code Management (4 أيام)
- Harmonized System codes per item
- Auto-suggest based on description
- Duty rates per code
- Restricted items flag

### 39.2 — Customs Declarations (8 أيام)
- Import declaration
- Export declaration
- Transit
- Temporary admission
- Re-export

### 39.3 — Duty Calculation (5 أيام)
- Customs duty (5% standard, varies)
- VAT on import (15% on CIF + duty)
- Excise tax (where applicable)
- Anti-dumping duties
- GCC origin (0% duty)

### 39.4 — Bayan Integration (10 أيام)
- API integration
- Submit declarations
- Track status
- Pay duties online
- Receive clearance

### 39.5 — Certificate of Origin (3 أيام)
- Saudi origin cert
- GCC certificates
- FTA certificates

### 39.6 — Landed Cost Calculation (4 أيام)
- CIF + Duty + VAT + Clearance + Inland transport
- Per shipment, per item
- Auto-update inventory cost
