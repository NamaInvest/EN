# توثيق التكامل مع مؤسسة التأمينات الاجتماعية (GOSI)

تم إنجاز **المرحلة 31** (GOSI Integration) من خطة العمل لضمان امتثال النظام (Compliance) للمعايير السعودية بشكل إلكتروني ومؤتمت تماماً.

## 🛠️ ما تم إنجازه تقنياً:

### 1. بناء الخدمة المركزية `GOSIService`
تم كتابة الكود الخاص بربط النظام بواجهة B2B API التابعة لمؤسسة التأمينات (GOSI).
- **مكان الملف:** `src/lib/gosi-service.ts`
- **المهام التي تقوم بها:**
  - **التسجيل التلقائي (`registerEmployee`):** إرسال بيانات الموظف، هويته الوطنية، راتبه الأساسي، وبدل السكن بمجرد إضافته للنظام.
  - **تحديث الرواتب (`updateSalary`):** أتمتة إرسال طلب التغيير في الأجر وقت تغيير العقود لضمان صحة الاحتساب في النظامين.
  - **التشفير والتوقيع:** تشفير حمولة الطلب (Payload) عبر خوارزمية `HMAC-SHA256` بالمفاتيح السرية للمنشأة لضمان الموثوقية الأمنية.
  - **إلغاء التسجيل (`deregisterEmployee`):** إسقاط الموظف من التأمينات بمجرد تسجيل إنهاء خدمته لأي سبب كان.

### 2. دمج النظام بشكل غير معيق (Non-blocking Integration)
تم دمج خدمة التأمينات بشكل ذكي داخل واجهات إضافة الموظفين الخاصة بالنظام دون التسبب في تبطيء أو تعليق النظام للمستخدم:
- **مكان التعديل:** `src/app/api/hr/employees/route.ts`
- **التصرف:** عند قيام قسم الـ HR بإنشاء موظف جديد (عن طريق `POST /api/hr/employees`)، يتم حفظ الموظف أولاً محلياً وإرجاع رد النجاح فوراً لسرعة الاستجابة، وفي الخلفية `Background Job` يتم إرسال بياناته آلياً للتأمينات للحصول على رقم الـ `gosiNumber`.
- **حل المشاكل المعقدة (`Zero-Errors`):** تم حل مشاكل أنواع البيانات (`Decimal` vs `Number`) أثناء تمرير الراتب من قاعدة البيانات لموفر الخدمة لضمان استقرار البناء (Compilation) بنسبة 100%.

### 3. الرفع والاعتماد
- تم التحقق من سلامة البناء واجتياز اختبار `npx tsc --noEmit` بنجاح مطلق.
- تم رفع التحديثات إلى السيرفرات المباشرة (Production) باستخدام الأداة المعتمدة `deploy.js`.

## 🔗 الروابط الخاصة بالعمليات والمراجعة

بالإمكان اختبار ومراجعة العمل الذي تم عبر الروابط/الواجهات التالية (في بيئة النظام المرفوعة حالياً):

1. **إضافة موظف جديد لاختبار الربط:**
   - الواجهة المباشرة (UI): توجه إلى `https://[Your-Domain]/hr/employees`
   - عند إضافة الموظف الجديد، سيقوم النظام تلقائياً بتنفيذ الاتصال مع `GOSIService` لتسجيله.

2. **احتساب اشتراكات GOSI الشهرية:**
   - الواجهة (UI): `https://[Your-Domain]/hr/gosi` (للاطلاع على ملخص التأمينات للشركة).
   - الـ API للتحقق (GET): `/api/hr/gosi` (لجلب الملخص والتكاليف).
   - الـ API للترحيل المالي (POST): `/api/hr/gosi` (لاستقطاع الرواتب وإنشاء القيود المحاسبية لصاحب العمل والموظفين).
