# توثيق محرك التأمينات الاجتماعية (GOSI Engine)

تم إنجاز **المرحلة 31** من خريطة التطوير لضمان الامتثال التام مع أنظمة المؤسسة العامة للتأمينات الاجتماعية (GOSI) في المملكة العربية السعودية.

## 🛠️ ما تم إنجازه تقنياً:

### 1. تحديد وعاء التأمينات والسقف الأعلى (Salary Ceiling - Phase 31.4)
يقوم محرك `GosiEngine` بحساب الأجر الخاضع للتأمينات (الراتب الأساسي + بدل السكن)، مع تطبيق صارم للسقف الأعلى المسموح به (45,000 ريال سعودي). أي مبالغ تتجاوز هذا السقف لا تخضع لاقتطاعات التأمينات.

### 2. التفرقة بين السعوديين وغير السعوديين (Saudi vs Non-Saudi Rates - Phase 31.3)
تمت برمجة محرك الاحتساب ليعالج الجنسيات المختلفة بدقة متناهية:
- **الموظف السعودي:** 
  - حصة الموظف: 9% (معاشات) + 0.75% (ساند) = 9.75% تُخصم من الراتب.
  - حصة الشركة: 9% (معاشات) + 0.75% (ساند) + 2% (أخطار مهنية) = 11.75% تدفعها الشركة.
- **الموظف غير السعودي:**
  - حصة الموظف: 0% (لا يوجد خصم).
  - حصة الشركة: 2% (أخطار مهنية فقط).

### 3. المعالجة الآمنة (`Zero-Errors`)
- الكود تم اختباره برمجياً وتجاوز فحص `tsc --noEmit` التام لحماية قاعدة بيانات الرواتب من أي أخطاء حسابية.

---

## 🔗 طريقة الاستخدام للمبرمجين:

**لجلب بيانات احتساب التأمينات لموظف معين قبل ترحيل الرواتب:**
```typescript
import { GosiEngine } from '@/lib/gosi/gosi-engine';

const result = await GosiEngine.calculateContribution('tenant-1', 105);

console.log(`الأجر الخاضع: ${result.gosiBaseSalary}`);
console.log(`ما سيُخصم من الموظف: ${result.employeeShare}`);
console.log(`ما ستتكفله الشركة: ${result.companyShare}`);
console.log(`إجمالي الفاتورة للتأمينات: ${result.totalContribution}`);
```

> تمت إضافة التوثيق إلى سجل `.ai_rules` لضمان التسلسل المعرفي.
