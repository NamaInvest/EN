# توثيق محركات البيانات والذكاء (Data & AI Engines - Phases 60 to 63)

تم إنجاز المحركات الخاصة بـ **(المرحلة 60)** والمتعلقة بالبنية التحتية للبيانات والتحليلات المتقدمة. تهدف هذه المرحلة إلى فصل أحمال العمل التحليلية (OLAP) عن أحمال العمل التشغيلية (OLTP)، بالإضافة لإدخال الذكاء الاصطناعي في مراقبة الجودة.

## 🛠️ ما تم إنجازه تقنياً:

### 1. مستودع البيانات (Data Warehouse Engine - Phase 60)
تم بناء محرك `DataWarehouseEngine` لإدارة تدفق البيانات (ETL):
- سحب البيانات التاريخية (فواتير، قيود) من قاعدة البيانات التشغيلية (PostgreSQL) لمنع الضغط عليها أثناء استخراج التقارير.
- إمكانية التصدير إلى صيغ عمودية عالية الأداء (مثل Parquet / DuckDB / BigQuery) لتشغيل تقارير الـ BI بسرعة فائقة.

### 2. كشف الشذوذ والاحتيال (Anomaly Detection Engine - Phase 63)
تم بناء محرك `AnomalyDetectionEngine` الاستباقي:
- حساب الانحراف المعياري (Standard Deviation) و (Z-Score) لاكتشاف نسب الخصم غير الطبيعية أو المشبوهة.
- رصد العمليات المالية النقدية الضخمة بالأرقام المدوّرة (Round-Number Transactions) والتي قد تشير إلى محاولات غسيل أموال أو احتيال.
