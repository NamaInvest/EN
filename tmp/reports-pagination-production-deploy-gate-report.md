## 2. خطة النشر وخطة التراجع (Deploy & Rollback Plans)

### أ. خطة النشر (Deployment steps)
1. الاتصال بخادم الإنتاج VPS عبر SSH.
2. سحب التعديلات من origin main (`git pull origin main`).
3. بناء نسخة الإنتاج للموقع المشترك (`npm run build`).
4. إعادة تشغيل التطبيقات في PM2 (`pm2 reload all` أو `pm2 restart all`).

### ب. خطة التراجع السريع عند الطوارئ (Rollback Strategy)
1. التراجع المحلي والبعيد عن الالتزام بالنشر الحقيقي:
   ```bash
   git reset --hard 883f254ecc7f62a91839fdf58c3c289e4d650770
   ```
2. إعادة البناء (`npm run build`).
3. إعادة تشغيل التطبيقات المشغلة (`pm2 reload all`).
