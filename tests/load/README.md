# دليل اختبارات الحمل والضغط باستخدام k6 (k6 Load & Stress Testing Guide)

يوضح هذا الدليل كيفية تثبيت وإطلاق اختبارات الحمل والضغط التلقائية لقياس قدرة خادم واجهات التطبيق (APIs) ونقاط البيع وصناعة الفواتير في نظام **Nama Invest ERP / Namasoft ERP**.

---

## 🛠️ 1. متطلبات التثبيت (Installation Requirements)

تعتمد اختبارات الحمل على أداة **k6** من شركة Grafana المصممة لقياس أداء المطورين.

### تثبيت k6 على نظام تشغيل Windows:
يمكن التثبيت عبر مدير الحزم Chocolatey أو winget مباشرة من سطر الأوامر:
```powershell
winget install grafana.k6
```
أو عبر Chocolatey:
```powershell
choco install k6
```

---

## 🧪 2. شرح سيناريوهات الاختبار المتوفرة (Test Scripts)

تتوفر سيناريوهات الاختبار في مجلد `tests/load/k6/`:

1. **اختبار المصادقة ودخول الكاشير (`k6/auth.js`)**:
   - **السيناريو**: محاكاة تصاعدية تبدأ بـ 0 وتنتهي بـ 50 مستخدماً وهمياً متزامناً (VUs) يقومون بطلبات تسجيل دخول متكررة للتأكد من استقرار بوابة الدفع ومقاومة الاختناق.
   - **حدود القبول (Thresholds)**: يجب أن تكمل 95% من الطلبات في زمن أقل من 500 ملي ثانية (`p(95)<500`).

2. **اختبار إنشاء الفواتير المتزامنة (`k6/invoice-creation.js`)**:
   - **السيناريو**: محاكاة 20 مستخدماً وهمياً متزامناً يقومون بحفظ وإنشاء فواتير مبيعات متكررة لشركات مختلفة لاختبار عزل المستأجرين وسرعة كتابة وحفظ القيود المحاسبية.
   - **حدود القبول (Thresholds)**: يجب أن يكتمل حفظ الفاتورة وتوقيعها في زمن أقل من 1000 ملي ثانية (`p(95)<1000`).

---

## 🚀 3. أوامر تشغيل الفحوصات وتوليد التقارير (Run Commands)

تأكد من تشغيل خادم التطبيق محلياً أولاً (`npm run dev` أو خادم الإنتاج التجريبي على المنفذ 3000)، ثم شغل الأوامر التالية من المجلد الرئيسي للمشروع:

- **لتشغيل اختبار المصادقة**:
  ```bash
  k6 run tests/load/k6/auth.js
  ```
- **لتشغيل اختبار إنشاء الفواتير**:
  ```bash
  k6 run tests/load/k6/invoice-creation.js
  ```
- **تصدير تقرير النتائج إلى ملف JSON للتحليل**:
  ```bash
  k6 run --summary-export=tmp/k6-load-summary.json tests/load/k6/auth.js
  ```
