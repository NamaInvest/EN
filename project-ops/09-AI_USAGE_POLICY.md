# AI Usage Policy

## الهدف
استخدام الذكاء الصناعي بدون تخريب النظام.

---

# يسمح للـ AI بـ:

- كتابة boilerplate
- كتابة UI
- كتابة tests
- كتابة APIs
- كتابة docs
- refactor محدود

---

# ممنوع على AI

- تعديل accounting core مباشرة
- تعديل tenant isolation
- تعديل ZATCA logic
- destructive migrations
- rewrite كبير بدون موافقة

---

# أي تعديل AI يجب:

- مراجعته
- اختباره
- مقارنة business rules
- تحديث docs
